# Security policy

Report a vulnerability to the address in `public/.well-known/security.txt` (served at `/.well-known/security.txt`). Please do not open a public issue for one. Include what you found, how to reproduce it and the version or commit.

Owner action before launch: the contact in that file is still the placeholder `security@example.invalid`; replace it with a monitored address and set `Security:Contact` on the API to match (see `docs/static-host-headers.md`).

What the project already does is recorded in `docs/security-performance-plan.md` and the Phase D findings in `docs/review-and-completeness-plan.md`.
